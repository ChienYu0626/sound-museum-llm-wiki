# 流行音樂流派與代表音樂人 LLM Wiki 總索引

歡迎來到「經典與現代流行音樂流派與代表音樂人」知識庫。本知識庫採 Andrej Karpathy 所倡導的 LLM Wiki 架構持續維護，專門作為製作音樂新手教學 HTML 簡報的唯一知識來源（Single Source of Truth）。

## 1. 音樂流派概念頁 (Genres)

> 探索各大流行音樂流派的歷史起源、聽覺特徵與演化脈絡。

| 流派名稱 | 核心年代 | 新手一句話特徵 | 條目連結 |
| :--- | :--- | :--- | :--- |
| **搖滾樂 (Rock Music)** | 1950s - 至今 | 強勁 2/4 拍重音與轟鳴電吉他交織的熱血聲響 | [檢視條目](wiki/genres/rock.md) |
| **節奏藍調與靈魂樂 (R&B / Soul)** | 1940s - 至今 | 絲綢般滑順的身體律動（Groove）與喉音轉音 | [檢視條目](wiki/genres/r-and-b.md) |
| **華語流行 (Mandopop)** | 1930s - 至今 | 以優美親切的中文旋律為核心，融合多元西方風格的大眾情感共鳴 | [檢視條目](wiki/genres/mandopop.md) |
| **獨立搖滾與流行 (Indie Rock / Pop)** | 1980s - 至今 | 跳脫商業框架、直白接地氣的青年生活與熱血現場大合唱 | [檢視條目](wiki/genres/indie-rock.md) |

## 2. 代表音樂人條目頁 (Artists)

> 記錄推動流行音樂浪潮的靈魂人物、標誌性作品與新手必聽指南。

| 音樂人 / 樂團 | 核心流派 | 歷史定位與招牌特徵 | 條目連結 |
| :--- | :--- | :--- | :--- |
| **Beyond** | 搖滾樂、華語流行 | 香港傳奇樂團，將理想、自由與人道關懷化為熱血原創頌歌 | [檢視條目](wiki/artists/beyond.md) |
| **陶喆 (David Tao)** | 節奏藍調、華語流行 | 華語 R&B 教父，完美奠定中文歌曲的美式黑人靈魂律動與和聲標準 | [檢視條目](wiki/artists/david-tao.md) |
| **鄧紫棋 (G.E.M.)** | 華語流行、R&B、搖滾 | 新生代全能唱作天后，擁有極具穿透力的巨肺嗓音與大格局編曲 | [檢視條目](wiki/artists/gem-tang.md) |
| **周杰倫 (Jay Chou)** | 華語流行、R&B、嘻哈 | 跨時代音樂天王，將古典鋼琴、東方中國風與西方節奏完美融合的革命者 | [檢視條目](wiki/artists/jay-chou.md) |
| **皇后合唱團 (Queen)** | 搖滾樂、歌劇搖滾 | 英國殿堂天團，融合古典歌劇、多軌合唱與席捲體育場的群體感染力 | [檢視條目](wiki/artists/queen.md) |
